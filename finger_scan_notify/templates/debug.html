💚 Line Notify HTTP 200

      

        ✅ {"status":200} = สำเร็จ รับแจ้งเตือนได้เลย

        ❌ {"status":401} = Token ผิด หรือ revoke แล้ว

        ❌ {"status":400} = รูปแบบผิด
      

    

    

      
🏥 MOPH Alert HTTP 200

      

        ⚠️ {"message":"Successfully"} = API รับแล้ว

        แต่ผู้รับต้อง Subscribe ใน App ก่อนถึงจะได้รับ

        ❌ 401/403 = Key ผิด
