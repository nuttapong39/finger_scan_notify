# ปรับ UI ให้ Minimal + Appearance สว่าง/มืด + ไอคอน Lucide / Simple Icons

สถานะ: ลงมือแล้ว (8 พ.ย. 2569) — ทดสอบด้วย Chrome ทั้งสองโหมดแล้ว

## เป้าหมาย
หน้าเว็บของ Admin ทุกหน้า (รวม login) ดูเรียบ น้อยองค์ประกอบ มี **Appearance** สองแบบคือ สว่าง (เริ่มต้น) และ มืด
ใช้ไอคอนชุดเดียว (Lucide) แทน emoji ทั้งหมด และโลโก้แบรนด์จาก Simple Icons เฉพาะที่จำเป็น

## ขอบเขต
- ปรับหน้าตาอย่างเดียว ไม่เปลี่ยนเมนู ฟีเจอร์ API หรือพฤติกรรม
- ไม่แตะ Flex card ที่ส่งไป LINE (LINE ไม่รองรับ SVG จากเว็บ) พรีวิวการ์ดในหน้าแก้ไขยังแสดงสีของการ์ดตามเดิมทั้งสองโหมด
- ภาษาในหน้าเว็บคงเป็นไทย

## การตัดสินใจ
| # | เรื่อง | ตัดสินใจ |
|---|---|---|
| Q1 | คำเรียก | **Appearance** (โหมดสี) = สว่าง/มืดของหน้าเว็บ ส่วน **Theme** ยังหมายถึง Flex card (ดู `CONTEXT.md`) |
| Q2 | แหล่งไอคอน | เก็บเฉพาะ SVG ที่ใช้ในโปรเจกต์เป็น sprite เสิร์ฟเอง ไม่พึ่ง CDN, ไม่มี library JS; ใบอนุญาต Lucide = ISC, Simple Icons = CC0 (เก็บไฟล์ LICENSE ไว้ข้าง sprite); ฟอนต์ยังใช้ Google Fonts + fallback ฟอนต์ระบบ |
| Q3 | สลับโหมด | ปุ่มสลับ (`sun`/`moon`) ที่ sidebar และหน้า login; จำใน browser (localStorage) ต่อเครื่อง; เปิดครั้งแรก = สว่างเสมอ ไม่ตามค่าระบบปฏิบัติการ; สคริปต์ใน `<head>` ตั้งโหมดก่อนวาดหน้า กันกะพริบ |
| Q4 | Minimal | design token ชุดเดียวใน `base.html` มีค่าแยกสว่าง/มืด; เทาล้วน + สีเน้นน้ำเงินสีเดียว; เขียว/แดง/เหลืองใช้กับสถานะเท่านั้น; ตัดเงา gradient glow ใช้เส้นขอบบาง; ลดระดับน้ำหนัก/ขนาดตัวอักษร; ตารางเบา; ปุ่มหลักหนึ่งปุ่มต่อการ์ด; sidebar = ไอคอน + ชื่อ |
| Q5 | Logo / Thumbnail | favicon = โลโก้โรงพยาบาล; รายชื่อบุคลากรใช้วงกลมตัวอักษรย่อ (ไม่ดึงรูปถ่ายจาก hosoffice); โลโก้แบรนด์: LINE (token / Flex card), MySQL (ตั้งค่า hosoffice), SQLite (ข้อมูลของแอป); โลโก้โรงพยาบาลที่ sidebar + login เสิร์ฟ `logo_ck.png` จากเซิร์ฟเวอร์เอง |

## งานที่ต้องทำ
1. เสิร์ฟไฟล์ static (`static/`: sprite, โลโก้, favicon) — ปัจจุบันยังไม่มีโฟลเดอร์; `static` เป็น endpoint สาธารณะอยู่แล้วใน `auth.PUBLIC_ENDPOINTS` (login ต้องใช้) และ nginx ต้องไม่บล็อก
2. สร้าง sprite จาก Lucide + Simple Icons เฉพาะที่ใช้ แล้วแมป emoji ~180 ตำแหน่งใน 13 template เป็นไอคอน (รวมข้อความ toast / สถานะในหน้า)
3. เขียน CSS token กลางใหม่ใน `base.html` + `login.html` (สว่างเป็น `:root`, มืดเป็น `[data-appearance="dark"]`)
4. ปุ่มสลับ Appearance + สคริปต์ตั้งค่าก่อนวาดหน้า
5. วงกลมตัวอักษรย่อในรายการบุคลากร; favicon
6. ตรวจด้วย Chrome ทั้งสองโหมด ทั้งจอกว้างและจอแคบ ทุกหน้า; ตรวจคอนทราสต์ตัวอักษรอย่างน้อย AA

## ความเสี่ยง
- emoji บางตัวอยู่ในข้อความที่ server สร้าง (message ของ API) — ต้องย้ายไอคอนไปฝั่งหน้าเว็บ ห้ามเปลี่ยนข้อความที่ test ตรวจอยู่โดยไม่ดู test
- ข้อความ/สถานะที่ใช้ emoji เป็นตัวแยก (เช่น ✅/❌ ใน JS) ต้องแมปเป็นคลาสสถานะ ไม่ใช่แค่เปลี่ยนตัวอักษร
- ไม่มีชุดทดสอบ UI อัตโนมัติ — ใช้ test ที่มี (ตรวจ HTML/route) + ตรวจด้วยสายตาใน Chrome
