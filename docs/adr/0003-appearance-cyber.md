# 0003 — Appearance: Cyber (แทนโหมดมืดเดิม) และหน้า Login แบบเทอร์มินัล

สถานะ: ยอมรับ (8 พ.ย. 2569) · แทนที่บางส่วนของ `docs/design/ui-minimal-light-dark.md`

## บริบท
การปรับ UI รอบก่อนตัดสินว่า Appearance มีสว่าง/มืด **เริ่มต้นสว่าง** และ Minimal (ตัดเงา gradient glow)
ทีมต้องการให้ทั้งระบบมีบุคลิก Cyber Security พร้อมพื้นหลังแบบ Terminal โดยใช้ `login1.html`/`login2.html` เป็นต้นแบบ
(`login1.html` ไม่ครบ ตัดจบที่บรรทัด 291 ; `login2.html` ครบแต่เป็นเทมเพลต Django)

## ตัดสินใจ
1. โหมดมืดเดิมเปลี่ยนชื่อและหน้าตาเป็น **Cyber** และเป็น **ค่าเริ่มต้น** ; **สว่าง** ยังอยู่ (เรียบเหมือนเดิม) สลับได้ต่อ browser
   ค่าที่จำไว้เดิม `dark` ถูกอ่านเป็น `cyber`
2. หน้า **เข้าสู่ระบบเป็น Cyber เสมอ** ไม่มีปุ่มสลับ Appearance (มีเฉพาะปุ่ม FX) เพื่อดูแลดีไซน์เดียว
3. เอฟเฟกต์เคลื่อนไหว (ฝนตัวอักษร, scanlines, glitch, glow) อยู่ที่หน้า Login เท่านั้น มีปุ่ม FX จำใน browser ปิดอัตโนมัติเมื่อระบบตั้ง `prefers-reduced-motion`
   ไม่มี boot screen ; หน้าอื่นใช้ palette Cyber แต่**ไม่มีเอฟเฟกต์เคลื่อนไหวและไม่มี scanlines** (ตารางภาษาไทยต้องอ่านง่าย คอนทราสต์ผ่าน AA)
4. ฟอนต์ฝังในโปรเจกต์ (`static/fonts/`, ใบอนุญาต OFL) ไม่พึ่ง Google Fonts : IBM Plex Sans Thai, IBM Plex Mono, Orbitron
5. ของตกแต่งที่ดูเหมือนข้อมูลระบบ (log, มิเตอร์) ต้องไม่อ้างสถานะจริง — ไม่มีป้าย `SECURE`/`ONLINE`/TLS ที่ไม่ได้ตรวจ และไม่แสดง IP ผู้ใช้ในหน้าที่ยังไม่ล็อกอิน
6. ข้อความที่ผู้ใช้ต้องอ่านเป็นภาษาไทย ; ป้ายอังกฤษแบบเทอร์มินัลใช้เป็นของตกแต่งเสริมเท่านั้น
7. Theme ของ Flex card (สีการ์ดที่ส่งไป LINE) ไม่เกี่ยวและไม่เปลี่ยน

## ทางเลือกที่พิจารณา
- **Cyber เป็นโหมดเดียวทั้งระบบ (ลบสว่าง):** ตรงเจตนาที่สุดแต่ตารางข้อมูลภาษาไทยจำนวนมากบนจอมืดล้วนล้าตาในห้องทำงานที่สว่าง และต้องรื้อ test ทั้งหมด — ไม่เลือก
- **หน้า Login ตามโหมดที่จำไว้ (สว่างแสดงการ์ดเรียบ):** ต้องดูแลสองดีไซน์ — ไม่เลือก
- **ใช้ Google Fonts ตามเดิม:** เซิร์ฟเวอร์ในเครือข่ายโรงพยาบาลอาจเข้าอินเทอร์เน็ตไม่ได้ หน้าตา Terminal จะหายเงียบๆ — ไม่เลือก

## ผลที่ตามมา
- ต้องแก้ test ที่ว่า "ทุกหน้ามีปุ่มสลับ Appearance" ให้ยกเว้นหน้า Login และแก้ test ที่อ้าง `dark`
- เพิ่มไฟล์ฟอนต์ใน repo (ราว 300–500 KB) พร้อมไฟล์ใบอนุญาต
- เอฟเฟกต์ที่หน้า Login กิน CPU บนเครื่องเก่า จึงต้องมีปุ่ม FX และปิดเองตามค่า reduced-motion
- ระดับ glow/เงาของหน้าอื่นกลับมาได้บางส่วน (เฉพาะสีเน้น ไม่ใช่เอฟเฟกต์) ขัดกับหลัก "ตัดเงา glow" เดิม
